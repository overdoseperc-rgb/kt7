# КТ №7 Пользовательские исключения

## Вариант 1 — BankAccount

Проект реализует собственную иерархию исключений для банковского счёта.

Созданы классы:

- BankingException — базовое исключение банковской системы.
- InsufficientFundsException — возникает при попытке снять сумму больше текущего баланса.
- InvalidAccountException — возникает при неверном формате номера счёта.
- BankAccount — класс банковского счёта.

В программе демонстрируются:
- создание счёта;
- проверка номера счёта;
- снятие денежных средств;
- обработка конкретных исключений;
- общий обработчик BankingException.

Требования задания выполнены:
- исключения наследуются от Exception;
- классы находятся в отдельных файлах;
- реализованы стандартные конструкторы;
- добавлены дополнительные свойства исключений.
